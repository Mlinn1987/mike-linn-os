# Notion backups

Read-only copies of Mike OS Notion databases, so the system isn't solely dependent on Notion.

- **Never edit these files.** Notion stays the primary home for this data.
- **Level 0–1 content only.** Health, finances, family details and other Level 2 fields must be left out or redacted before saving.
- Each backup records when it was taken and the source database ID.

Empty for now. Backups start once the Notion integration can read.
